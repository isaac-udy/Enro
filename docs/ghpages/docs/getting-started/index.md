# Getting Started

Read these three pages in order to add Enro to a project and build a first
screen.

- [Installation](installation.md) — the Gradle dependencies and the install
  call for each platform.
- [Basic Concepts](basic-concepts.md) — a definition of each Enro term.
- [Your First Screen](your-first-screen.md) — an example with three screens,
  navigation between the screens, and a result.

To upgrade an Enro 2 app, read [Migrating from Enro 2](../migrating-from-v2.md)
first.
